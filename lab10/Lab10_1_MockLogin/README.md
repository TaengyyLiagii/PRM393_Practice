# Lab10_1_MockLogin

## Description
Mock login app with form validation and simulated backend authentication.

## How to Run
```bash
cd Lab10_1_MockLogin
flutter pub get
flutter run
```

## Features
- Email + password validation (Flutter Form)
- Simulated 1.5s authentication delay
- Mock token generated on success
- Navigation to Home screen on success
- Error message displayed on invalid credentials
